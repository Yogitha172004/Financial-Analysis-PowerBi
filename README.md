
# 📊 Financial Analysis Dashboard — Power BI

An interactive financial analytics dashboard designed to analyze
transaction performance, customer segments, financial KPIs and risk-related
transaction data using Microsoft Power BI.

## 📌 Project Overview

This project provides an interactive two-page financial analysis experience
designed to move from high-level business insights to transaction-level
investigation.

## 📑 Dashboard Pages

### 1. Overview Analysis

- Financial KPI cards
- YoY performance analysis
- Monthly transaction trends
- Transaction status analysis
- Customer segment analysis
- State-wise transaction analysis
- Transaction type performance
- Gender-based transaction analysis
- Dynamic metric selection

### 2. Transactions

- Transaction-level details
- Transaction ID
- Transaction date
- Customer information
- Transaction type
- Transaction status
- Customer segment
- State
- Amount
- Fees
- Tax

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Data Modeling
- Interactive Slicers
- Drill-through
- Page Navigation
- Parameters
- Conditional Formatting
- Dynamic Measures

## 📊 Key Features

- Dynamic financial metrics
- Year-based filtering
- Transaction-level drill-through
- Interactive navigation
- YoY growth analysis
- % of total analysis
- Conditional performance indicators
- Financial KPI tracking
